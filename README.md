# 🧟 植物大战僵尸 · 英语单词学习版（外研版三年级下册）

一个爸爸给自家三年级孩子做的背单词小游戏：把**外研版三年级下册的 189 个单词**（2024 新课标新版）做进了《植物大战僵尸》——**答对单词才有阳光**，攒够阳光才能种植物、打僵尸。孩子以为在玩游戏，其实每一局都在刷单词。

## 🎮 在线玩

- 线上地址：http://game.fuzekeji.cn/pvz/
- 纯静态项目，本地打开 `index.html` 即可玩，也可以部署到任何静态托管

## ✨ 核心特色

| 设计 | 说明 |
|---|---|
| 答对 = 奖励 | 答对一题阳光立刻到账（+150），攒阳光种植物、打僵尸 |
| 答错零惩罚 | 答错不扣任何东西，只是这道题下次出现得更频繁 |
| 科学复习 | FSRS 轻量间隔重复（1/2/4/7 天）+ 错题本自动加权，顽固错题（错 ≥3 次）反复考 |
| 难度由易到难 | 先再认（选择题）后回忆（拼写题）；拼写只对已答对的词开放 |
| 防沉溺 | 单局 8–12 分钟，学习进度零惩罚，无强制答题卡死 |
| 防"过轻松过关" | 僵尸随进度段位加速、错题权重让薄弱词反复出现、题型混搭 |
| 可玩性优先 | 保留原版玩法零损伤；大波题答对全场减速救场；专属道具阳光买不到 |

## 🧠 设计背后的理论

- **错题本 + 间隔复习**：艾宾浩斯遗忘曲线 / FSRS 间隔重复算法（Anki 同源）/ 测试效应——顺着遗忘曲线在快忘的时候复习
- **答对才给阳光**：操作性条件反射（即时强化）+ 可变比率强化（阳光暴雨、随机奖励，保持期待）
- **难度由易到难**：心流理论（挑战与能力匹配）+ 自我决定理论的"胜任感"
- **答错零惩罚**：习得性无助的反面——保护孩子的自信和内在动机
- **防沉溺/防过轻松**：健康游戏时长管理 + 挑战升级曲线，不让"背熟"变成"背串"

## 🛠️ 技术说明

- 原生 JavaScript + Canvas，**无框架、无构建、纯静态**，`file://` 协议直接可玩
- 学习层（答题/奖励/复习/错题本）为增量改造：`js/word-study.js`、`js/answer-ui.js`、`js/error-book.js`
- 词库：`data/words-3B-all.js`（外研版三起三年级下册全册，189 词，仅单词不含短语）
- 词库生成器：`tools/gen-words-from-md.cjs`（Markdown 单词表 → 词库，换教材可复用）
